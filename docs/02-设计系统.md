# 02 · 设计系统

> 奶油纸 + 墨黑硬边 + 4px 硬投影 + 五色强调。像手帐，不像企业后台。

## 一、颜色

```css
/* 底与墨（真实值见 src/styles/tokens.css） */
--paper: #fbf6ec;   /* 页面底 */
--paper-2: #f6eedd; /* 次级底/条纹 */
--paper-3: #fffdf7; /* 卡面，永远比底色亮一档 */
--ink: #1b1b1b;     /* 文字与边框 */
--ink-2: #3d3a35;   /* 次要文字 */
--ink-3: #6b665c;   /* 占位/辅助 */

/* 品牌色（hero band、卡片强调、图表） */
--coral: #ff6f61;   /* 主色，登录页品牌区 */
--coral-deep: #e8503f;
--sun: #ffd84d;     /* 高亮，选中 tab / 号牌 */
--mint: #7fd9c4;
--sky: #9fd3f2;
--pink: #ffb3c7;
--pink-deep: #f06c91; /* logo 的 comic 粉块 */
--lilac: #c7b4f2;

/* 状态色，与 STATUS_META.token 对应 */
--st-want: #c7b4f2;
--st-watching: #9fd3f2;
--st-watched: #7fd9c4;
--st-hold: #d6cfc0;
--st-drop: #f5a3a3;

/* 背景照片与薄纱：--veil 0 = 原图，1 = 全纸色 */
--bg-photo: url('/bg/sakura.jpg');
--veil: 0.55;
```

用法：强调块用五色，**文字永远墨黑**（五色上都够对比度）；不用纯白、不用灰阶渐变。

## 三、间距与形状

- 间距刻度 `--sp-1..8` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 边框：统一 `2px solid var(--ink)`；强调块 `3px`。
- 圆角：`--r-sm 2px`、`--r-md 8px`、`--r-lg 14px`、`--r-pill 999px`。
- 阴影只有三档硬投影，**不带模糊**：
  ```css
  --shadow-hard-sm: 2px 2px 0 var(--ink);
  --shadow-hard: 4px 4px 0 var(--ink);
  --shadow-hard-lg: 6px 6px 0 var(--ink);
  ```
- 悬停：上移 1px + 阴影加一档；按下：归零位置 + 阴影归零。

### 背景照片与薄纱
`App.vue` 第一层是固定定位的 `.app-bg`（`src/styles/base.css`）：

```html
<div class="app-bg" aria-hidden="true"></div>
```

- 照片来自 `public/bg/sakura.jpg`（1280px 宽、约 190KB），`background-size: cover`，页面滚动时不动。
- 照片之上是 `.app-bg::after` 的 `rgba(251,246,236,var(--veil))`，`--veil: 0.55` 就是"55 薄纱"。想更清楚把 `--veil` 调小，想更淡调大，全站一起变。
- 纸色点阵在 `body::before`，z-index 比 `.app-bg` 高，所以点阵压在薄纱上面。
- 不要用 `background-attachment: fixed` 的 body 背景（移动端会抖），也不要给 `body` 加 opacity（会连内容一起淡掉）。

## 七、composables

```js
// 表单：字段、错误、校验、提交态
import { useForm, required, minLength, maxLength, pattern, sameAs, custom } from '@/composables/useForm'
const form = useForm({ username: '', password: '' }, {
  username: [required('请填写用户名'), minLength(2, '至少 2 位')],
  password: [required('请设置密码')],
})
form.values / form.errors / form.touched / form.setError(field, msg) / form.validate() / form.reset()

// 轻提示
import { useToast } from '@/composables/useToast'
const toast = useToast()   // toast.success/error/warning/info/dismiss，最多堆 3 条

// 分页（越界自动回第 1 页）
import { usePagination } from '@/composables/usePagination'
const { page, pageSize, total, totalPages, paged, next, prev, go } = usePagination(source, { pageSize: 8 })

// 统计（三个页面同一个口径，别各自算）
import { useStats } from '@/composables/useStats'
const { stats, entries, posts } = useStats()          // stats 是 computed
// stats.total/favorite/watched/watching/want/hold/drop、watchedEpisodes、watchedHours、
// avgScore、scoredCount、statusDistribution、scoreBuckets、scoreHigh/scoreMid、
// tagPreference、tagMax、months、heatMax、postCount、likesReceived、commentsReceived
```

统计口径（写死，别改）：平均分只算 `score !== null` 的条目；已看完 = `status === '看过'`；收藏 = `favorite === true`；时长按每集 24 分钟估算。

## 八、样式纪律

1. 只用 token，不写裸色值（`#FF6F61` 只允许出现在 tokens.css）。
2. 组件内 `<style scoped>`，需要全局的放 base.css / utilities.css。
3. 不用 `!important` 修样式，先想选择器层级。
4. 动画 120–180ms，缓动 `--ease-out`；关掉 `prefers-reduced-motion` 下的位移。
5. 焦点必须可见：`:focus-visible` 统一 3px 珊瑚描边。
