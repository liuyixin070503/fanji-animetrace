# 01 · 数据接口契约（db.js）

> 冻结日 11-27。冻结后新增字段可以，改签名/删函数必须先发 RFC 给 A，24 小时内答复。

## 一、四条铁律

1. **页面只调 `src/data/db.js`**。不准 import `seed.js` 读业务数据，不准碰 `localStorage`。
2. **全部同步**，不返回 Promise（localStorage 本来就同步，别包 async 增加复杂度）。
3. **返回副本**。页面直接改返回值不会改库，改完要 `saveXxx()` 落盘。
4. **写操作校验在 db 里**，页面只负责把错误显示出来。

## 二、错误约定

两种形态，别混用：

- 会抛的（程序员错误，正常流程不该发生）：`throw new Error('[db] addComment 需要登录用户')`。例如未登录写数据、缺主键。
- 会返回的（用户输入错误，属业务）：`{ ok: false, field: 'username', message: '用户名已被占用' }`。登录注册用这种，页面把 `field` 定位到表单项下面。
- 成功：`{ ok: true, user }` / `{ ok: true, entry }` 之类，或者直接返回实体。

## 四、实体字段

### Anime（种子常量，不进存储）
```js
{ id, title, titleJp, year, type: 'TV' | '剧场版', episodes, studio,
  tags: string[], summary, cover: { src, source, credit },
  accent,            // 卡片强调色（设计 token 之一）
  externalScore,     // 参考评分，展示用
  popularity }       // 热度，排序用
```

### User
```js
{ id, username, nickname, avatarSeed, bio, joinedAt, passwordDigest }
```
`passwordDigest` 永远不出 db.js（`publicUser()` 统一剥离）。

### JournalEntry
```js
{ id, userId, animeId,
  status,            // 想看 | 在看 | 看过 | 搁置 | 弃番
  progress,          // 看到第几集
  score,             // 0.5 步进，null = 不打分
  favorite,          // 是否收藏
  review,            // 短评 <= 200 字
  quote,             // 金句 <= 60 字
  mood: string[],    // 心情标签，最多 3
  tags: string[],
  startedAt, finishedAt, createdAt, updatedAt }
```

### Post / Comment
```js
Post    { id, authorId, animeId?, board, title, content, createdAt, likedBy: string[] }
Comment { id, postId, authorId, content, createdAt }
```

## 五、存储结构

```json
{
  "version": 1,
  "users":    [ /* User */ ],
  "session":  { "userId": "u_xxx", "expiresAt": 1730000000000 },
  "journal":  [ /* JournalEntry */ ],
  "posts":    [ /* Post */ ],
  "comments": [ /* Comment */ ]
}
```

键名 `fanji.db.v1`。版本号变化时在 `load()` 里做迁移，迁移失败直接重灌种子并在控制台警告。

## 六、枚举与常量（types/db.js）

| 导出 | 内容 |
| --- | --- |
| `STATUS` | `{ WANT:'想看', WATCHING:'在看', WATCHED:'看过', HOLD:'搁置', DROP:'弃番' }` |
| `STATUS_LIST` | 五个状态的固定顺序，图表/筛选按它遍历 |
| `STATUS_META` | 每个状态的 `{ label, token, emoji }`，`token` 指向 CSS 变量名 |
| `BOARDS` | `['讨论','求推荐','吐槽','资源情报']` |
| `MOODS` | 心情标签池（最多选 3） |
| `TAG_POOL` | 标签池，C 的表单和 B 的快捷筛选共用 |

## 七、校验规则（页面与 db 双重把关）

| 场景 | 规则 |
| --- | --- |
| 用户名 | 非空、去除首尾空格、唯一（大小写不敏感） |
| 昵称 | 非空（会显示在帖子里） |
| 密码 | 非空，本地模拟不做强度要求 |
| 手帐进度 | 0 ≤ progress ≤ 番剧总集数；状态改「看过」自动补满 |
| 评分 | 0.5 步进；null 不计入平均分 |
| 短评 / 金句 | ≤ 200 / ≤ 60 字 |
| 帖子 | 标题 5–40 字，正文 10–500 字 |
| 评论 | 10–200 字 |

## 八、别做的事

- 不要在组件里 `localStorage.setItem('fanji.db.v1', ...)`——绕过 dbTick，页面不刷新。
- 不要把 `listAnime()` 的结果存进 localStorage——目录是常量，存了就会和 seed 不一致。
- 不要在 db.js 里 `import` 任何 Vue 组件或路由。
- 不要给 db 加异步签名「反正以后要接后端」——真接后端时整层重写，比留半异步接口干净。
